# Gestion-de-Informacion-mediante-el-uso-de-Software
creación de practicas y actividades con el uso de softwares
github es la plataforma de alojamiento de código fuente y colaboración más grande del mundo, esencial para el desarrollo moderno basado en Git. Ofrece una interfaz web intuitiva sobre el sistema de control de versiones Git, facilitando la gestión de proyectos de software. algunas de sus características son las siguientes:

Características Principales de GitHub:

**Alojamiento de Repositorios:** Almacena repositorios de Git públicos y privados, permitiendo trabajar en la nube.
**Colaboración y Gestión:** Facilita el trabajo en equipo a través de Pull Requests, revisiones de código y Code Review.
**GitHub Actions:** Automatización de flujos de trabajo (CI/CD), permitiendo compilar, probar y desplegar código automáticamente.
**GitHub Copilot:** Asistente de IA integrado que sugiere código en tiempo real, aumentando la productividad y reduciendo errores.
**Documentación y Wiki:** Permite crear documentación centralizada para proyectos mediante archivos README y wikis.
**Gestión de Proyectos:** Ofrece tableros estilo Kanban (GitHub Projects), seguimiento de problemas (Issues) y control de versiones.
**Comunidad y Portafolio:** Funciona como una red social para desarrolladores, siendo ideal para mostrar proyectos propios (portafolio) y contribuir al software libre.
**Seguridad:** Incluye herramientas de escaneo de vulnerabilidades y gestión de secretos.

1. **¿Qué es un commit?**
   Un *commit* es un registro de los cambios realizados en un proyecto o archivo dentro de Git. Funciona como una “captura” del trabajo en un momento específico para poder guardar el progreso.

2. **¿Para qué sirve el historial de versiones?**
   El historial de versiones sirve para ver todos los cambios hechos en un proyecto, saber quién los realizó y poder regresar a versiones anteriores si ocurre algún error.

3. **¿Qué ventajas tiene GitHub para trabajo colaborativo?**
   GitHub permite que varias personas trabajen al mismo tiempo en un proyecto, compartan código, revisen cambios y mantengan todo organizado de manera segura en línea.

4. **¿Qué sucede si un archivo se elimina accidentalmente?**
   Si un archivo se elimina por accidente, normalmente puede recuperarse gracias al historial de versiones o regresando a un commit anterior donde el archivo todavía existía.

5. **¿Por qué es importante escribir mensajes claros en los commits?**
   Porque ayudan a entender qué cambios se hicieron en cada actualización. Esto facilita encontrar errores, organizar el proyecto y que otros colaboradores comprendan el trabajo realizado.
